# Pool Drill Book

Pool drills in the order you learn them, from your stroke to safeties and jump shots, with every table drawn to scale.

- Log a score on any drill. Hit the pass mark twice in a row and the drill is passed.
- **My session** builds a 30, 60 or 90 minute practice plan from where you are.
- Three views: big cards, a grid and a compact list. Filter by skill and difficulty.
- On a phone, add it to your home screen and it works offline after the first visit.

Scores are saved in your own browser.

Live site: https://sangpham2710.github.io/pool-drill-book/
